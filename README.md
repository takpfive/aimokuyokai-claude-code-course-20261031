# AI木曜会 Claude Code講座

2026年10月31日の基礎・実務編と、上級・業務設計編の配布教材です。ワンスライド・ワンメッセージで、実演しながら進めます。

**このリポジトリの会社名・取引・配信・行動履歴はすべて架空です。実在の会話履歴・顧客情報・社内資料は含みません。**

## 最初の5分

1. このページの **Code → Download ZIP** からダウンロードし、ZIPを展開する。
2. [公式Claude Desktop](https://claude.com/download)を開き、Codeタブを選ぶ。
3. このREADMEと`CLAUDE.md`があるフォルダーを作業場所に選ぶ。
4. 「このフォルダーの中身と、できる演習を教えてください」と送る。
5. [プロンプト集](docs/prompts.md)の演習01から始める。

Macを使った実演画面を収録しています。Windowsの準備とCLI補足は[セットアップ](docs/SETUP.md)を参照してください。機能・契約・組織設定は変わるため、参加直前に公式案内も確認してください。

## 演習一覧

| 演習 | 材料 | 完成物 | まず見る合格条件 |
|---|---|---|---|
| 01 フォルダー整理 | `starter/01-folder` | コピー6件・対応表 | 原本保持、重複と不明を区別 |
| 02 業務用アプリ | `starter/02-app` | 問い合わせ管理HTML | 検索、状態変更、再読込保存 |
| 03 根拠付き日報 | `starter/03-report` | `daily-report.md` | 予定・下書きを完了にしない |
| 04 三点照合 | `starter/04-match` | 全請求行の判定と根拠 | 7行中6行の例外を残す |
| 05 メール効果分析 | `starter/05-campaign` | 指標定義付き集計 | 重複・自動クリック・未帰属を分ける |
| 06 並列レビュー | `starter/06-review` | 2担当の指摘と統合メモ | 未確認条件を埋めずに残す |

`starter/`は原本、`output/`は講師がClaude Codeで実行した完成例です。自分の演習では別コピーのフォルダーを使うか、出力先を`my-output/`へ指定してください。削除・本番更新・外部送信は演習に含みません。

## アプリを開く

`output/app/index.html`をブラウザで開けます。講師は次の方法でChromeから操作検証しました。

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory output/app
```

ブラウザで <http://127.0.0.1:8765/index.html> を開きます。Windowsで`python3`が無い場合は`py -3`に置き換えてください。停止はターミナルでCtrl+C。アプリ内の基準日は2026-10-29固定です。

## 上級演習を再実行する

Python 3の標準ライブラリだけで動きます。

```sh
python3 output/04-match/match.py
python3 output/05-campaign/campaign.py
python3 verify.py
```

`verify.py`は今回の架空ケースの期待値を確認します。一般の業務データの正しさを保証するものではありません。
